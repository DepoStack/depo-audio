# Matt Pocock's skills in this repo

Copied unchanged from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `abeeaf9` (v1.3.2, 2026-11-19), MIT licensed (`LICENSE-mattpocock-skills.txt` in this folder).

## What's here

| Skill | Use it for |
| --- | --- |
| `/grill-with-docs` | Interview before a change, sharpening terms and recording decisions as you go |
| `diagnosing-bugs` | Hard bugs and slowdowns: reproduce, minimise, fix, regression-test |
| `tdd` | Red-green-refactor, one vertical slice at a time |
| `/improve-codebase-architecture` | Survey for deepening opportunities, then grill through one |
| `/handoff` | Compact a session into a handoff doc for the next agent |
| `/retro` | After a session, suggest fixes to the agent's environment (CLAUDE.md, checks, tools) |
| `wizard` | Generate a bash walkthrough for steps only a person can do |
| `/to-spec` | Turn the conversation into a spec issue |
| `/to-tickets` | Break a plan into blocking-linked issues |
| `/triage` | Move issues through the triage labels |
| `/implement` | Build a spec or ticket with tdd, then review |
| `/wayfinder` | Plan work too big for one session as a map of decision issues |

Helpers the above call: `grilling`, `domain-modeling`, `codebase-design`, `writing-for-agents`, `prototype`, `research`, `setup-matt-pocock-skills`.

Not copied: `grill-me` (not needed: `/grill-with-docs` calls `grilling` directly), `code-review` (Claude Code's built-in `/code-review` has the same name, and `/implement` uses that one), `pr`, `teach`, `to-questionnaire`, `wait-what`, `ask-matt`, `implement-spec`, the misc skills and the in-progress (beta) skills.

## Updating

Re-copy the folders from a newer commit of mattpocock/skills and update the commit above. Local edits to the copied skills are allowed (the repo encourages it) but get overwritten on update, so prefer putting repo-specific rules in `docs/agents/*.md`.
